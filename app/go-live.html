Go live guide

Put your app on your own link.

No code, no terminal. You click buttons in three websites, and your app gets its own address that you can share and show on Demo Day.

AI STUDIO→ GITHUB→ VERCEL→ LIVE LINK
PART 1 · ONCE

Two free accounts

1

Create a GitHub account

Go to github.com and sign up with your personal Gmail. GitHub is where your app’s files are kept safe.

2

Create a Vercel account with GitHub

Go to vercel.com, choose Sign up, pick the free Hobby plan, then Continue with GitHub. Using GitHub here is what lets Vercel see your app later.

PART 2

Get your app ready

3

Ask AI Studio to prepare it for Vercel

Open your app in Google AI Studio (Build mode) and send this message. It prevents the most common problem, a blank page after going live.

SEND THIS IN AI STUDIOGet this app ready to deploy on Vercel. It must build with Vite using “npm run build”. Make sure index.html loads the entry file with a module script tag for /index.tsx. If the app has more than one page, add a vercel.json that sends every route to /index.html. Don’t change how the app looks.
PART 3

AI Studio → GitHub

4

Open GitHub in AI Studio’s settings

In your app in AI Studio, open Settings and find the GitHub tab. Sign in to GitHub when it asks, and allow access.

5

Create a repository and push

Create a new repository. Give it a short name in lowercase with dashes, like zainab-innerwear. Then push (save) your app to it. AI Studio writes the save message for you.

What’s a repository? Just a folder for your app that lives on GitHub. Every time you push, GitHub keeps a copy of that version.
PART 4

GitHub → Vercel

6

Import your repository

In Vercel, click Add New… then Project. Your GitHub repositories appear in a list. Click Import next to your app.

7

Deploy

Vercel recognises the app by itself (it should say Vite). Don’t change any settings. Click Deploy and wait about a minute.

8

Open your live link

When you see the confetti, click the picture of your app or Visit. Your link looks like zainab-innerwear.vercel.app. Open it on your phone too.

9

Put it on the board

Copy the link, open the Project Board, paste it on your card and move your card to Live.

AFTER

Changing your app later

↻

Change in AI Studio, push again

Make your change in AI Studio as usual, then push to GitHub from the same GitHub tab. Vercel notices and updates your live link by itself in about a minute. You never need to repeat Part 4.

IF SOMETHING GOES WRONG

Quick fixes

The live link shows a blank white page

Do step 3 again in AI Studio, push again, and wait a minute. This is almost always the missing script line that step 3 asks for.

Vercel says “Build failed”

Click the failed deployment, open Build Logs and copy the red lines. Paste them into AI Studio with: “Vercel failed to build with this error. Fix it without changing the design.” Then push again.

A page shows “404” when I refresh it

Ask AI Studio to add the vercel.json from step 3, then push again.

My app uses Gemini (real AI features)

For the class, keep AI features faked. A real key put in a browser app can be seen and used by anyone. Ask Aleem before adding a GEMINI_API_KEY to Vercel.

I want a nicer link

In Vercel, open your project’s Settings, then Domains, and edit the .vercel.app name. Custom domains (like .com.ng) come after Demo Day.
